## 新特性

- 加入了方解石系列方块。
- 加入了雕纹灵魂页岩。
- 加入了新的音乐唱片 flurry。
- 游戏内的各种界面现在支持使用键盘导航。

### 方块

#### 方解石系列

- 加入了方解石柱、方解石台阶、方解石楼梯和方解石墙，分别为方解石的柱、台阶、楼梯和墙变种。
- 加入了磨制方解石，是方解石的磨制变种。
    - 可以使用4个方解石合成，也可以通过切石获得。
    - 拥有台阶、楼梯和墙变种，可以通过合成或切石获得。
- 加入了磨制方解石砖，是磨制方解石的砖变种。
    - 可以使用4个磨制方解石合成，也可以通过切石获得。
    - 拥有台阶、楼梯和墙变种，可以通过合成或切石获得。

#### 雕纹灵魂页岩

- 可在远古城市的箱子中找到。

### 物品

#### 音乐唱片

- 加入了新的音乐唱片 flurry。
    - 音乐作者为 Hyper Potions。
    - 可以在雪屋地下室的箱子中找到。
    - 通过红石比较器输出的红石信号强度为7。

### 辅助功能

- 现在游戏内的各种界面支持使用键盘导航。
    - 创造模式物品栏和配方书暂时不支持此功能。
- 按 `Tab ↹` 将在槽位组间导航，按方向键（`↑` `↓` `←` `→`）则会在槽位组内的槽位间移动。
    - 切石机配方、织布机图案、附魔台附魔选项及村民和流浪商人的交易项也会被视为槽位。
- 可以对槽位执行以下操作：
    - 按 `↵ Enter` 或 `Space`，等效于按下鼠标左键。
    - 按 `Ctrl` + `↵ Enter` 或 `Ctrl` + `Space`，等效于按下鼠标右键。
    - 按 `⇧ Shift` + `↵ Enter` 或 `⇧ Shift` + `Space`，等效于按下 `⇧ Shift` + 鼠标左键。
    - 连按两次 `↵ Enter` 或 `Space`，等效于双击鼠标左键，这会将同种物品收集到同一个槽位里。
    - 按住 `↵ Enter` 或 `Space` 时使用方向键移动，等效于鼠标左键拖拽，这会将物品分配到经过的槽位中。
    - 快捷栏1-9和丢弃会作用于聚焦的槽位。

## 更改

### 方块

- 雕纹浮冰现在是红石导体。

### 生物

- 去除了冻尸纹理文件中的多余像素。
- 僵尸现在穿戴任意皮革盔甲时，不再会在细雪内转化为冻尸。
- 骷髅现在穿戴任意皮革盔甲时，不再会在细雪内转化为流浪者。
- 流浪者现在会在冰冻深海、冻洋、冰封山峰、冻河、尖峭山峰、积雪山坡生物群系生成。
- 鹦鹉现在能模仿冻尸的声音。
- 硫方怪现在可以吸收方解石柱、磨制方解石、磨制方解石砖和雕纹灵魂页岩，并转变为缓慢弹性原型。

### 游戏内容

- 现在着火的生物免疫冰冻。

### 命令格式

- `/effect` 的 `effect` 参数现在可以接受一个状态效果标签。
- 现在具有 `minecraft:time` 类型的参数的值若大于2147483647（2^31-1）游戏刻，则会导致命令无法解析。

### 常规

- 更新了主菜单全景图以匹配2026年第4次小更新。
- 调试模式：
    - 现在可以在调试模式世界中正常更改、破坏或放置方块。
    - 调试模式世界中的方块不再会随着版本更新自动更新。
    - 现在调试模式世界内会包含每种实体各一个。
        - 若实体具有幼年变种，幼年变种会生成在对应实体的上方。
    - 现在会在每一次加载调试模式世界时自动停止游戏刻流逝。
    - 现在调试模式世界的难度锁定为普通。
    - 现在以下游戏规则会被强制设置为 `false`：
        - “游戏内时间流逝”（`advance_time`）。注：游戏在此之前就已经会设置此游戏规则，但更新日志错误地暗示不会。
        - “天气更替”（`advance_weather`）。注：游戏在此之前就已经会设置此游戏规则。
        - “生成流浪商人”（`spawn_wandering_traders`）。
        - “允许TNT被点燃并爆炸”（`tnt_explodes`）。
- 选项：将“图形API”选项设为“默认”时，游戏会随机从Vulkan和OpenGL中选取一种使用。
    - 此更改旨在测试近期的更改对两种图形API的影响，会在之后的快照中回退。

### 用户界面

- Realms界面中的“开始游戏”按钮的背景现在是紫色的。
- 鼠标悬停在列表项上时，该列表项会带有灰色描边。
- 修改了使用键盘导航到输入框时的行为。
    - 使用 `Tab ↹` 导航到输入框时，输入框会获得焦点并可编辑。
    - 使用方向键（`↑` `↓` `←` `→`）导航到输入框时，输入框会被高亮，但不可编辑。
        - 按 `↵ Enter` 或 `Space` 会使其变为可编辑的。
- 现在使用键盘导航时，鼠标指针会被隐藏，直至移动鼠标。
- 为配方书按钮加入了提示框。

### 辅助功能

- 复述功能现在会朗读游戏内的各种界面中的槽位信息。
    - 物品槽位的以下信息会被朗读：内容物、物品提示框及特殊槽位（如盔甲槽、燃料槽、药水槽）的名称。
    - 槽位的位置信息也会被朗读，这包括槽位在组内的顺序或是槽位在网格中的行号和列号。
- 切石机配方和织布机图案的行号和列号及附魔台附魔选项及村民和流浪商人的交易项组内的顺序会被朗读。
- 聚焦到一个槽位组时，可用于在此槽位组中移动的方向键会被朗读。

### 标签

- 移除了 `#swimming` 和 `#flying` 实体类型标签。

## 技术性更改

- 数据包版本现在为 126.0。
- 资源包版本现在为 102.0。
