# Minecraft 26.4 快照 6

### Minecraft Java 版快照

这里越来越冷了！本周的 26.4 快照 6 带来了雪砖，这套全新的建筑方块能让你的建筑看起来更加“酷” ;) 我们还为硫方怪家族加入了新的原型：低温。这位冰凉的小伙伴可懂得不少关于冰的知识。

保持冷静，祝建造愉快！

## 新特性

- 加入了雪砖
- 加入了新的硫方怪原型：低温

### 雪砖

- 雪砖可以用雪块以 2×2 的排列合成
- 雪砖有台阶、楼梯和墙变种
- 无法使用切石机制作雪砖台阶、楼梯和墙
- 雪砖属于硫方怪的快速滑行原型
- 雪砖只有使用锹挖掘时才会掉落自身

### 低温硫方怪原型

- 一种属于特殊原型类别的新硫方怪原型
- 具有与快速滑行原型相同的属性，但能够浮在水面上，并在移动时将下方的水替换为一片圆盘状的霜冰，类似冰霜行者魔咒
- 水方块上方必须是空气方块，才能放置霜冰
- 只有在硫方怪开始移动时处于着地状态，才会放置霜冰
- 硫方怪吸收蓝冰方块时使用此原型

## 更改

- 更改了默认 JVM 选项
- 在某些情况下，穿过熔岩下落的生物可能会受到略少的摔落伤害

### 方块、物品和实体的小幅调整

- 所有浮冰砖变种现在都需要使用镐挖掘，才会掉落自身
- 流浪者站在脆冰上方时不再使其碎裂

### 音效

- 为冰晶加入了环境音效
  - 如果冰晶方块下方有浮冰方块，它就有概率播放环境音效

### 默认 JVM 选项

- 游戏现在会根据系统的内存容量自动设置 Java 堆大小，最多使用系统内存的 25%，上限为 4 GB

## 技术性更改

- 数据包版本现在为 125.1
- 资源包版本现在为 101.0

## 数据包版本 125.1

### 硫方怪原型

- 加入了新的 `location_based_effects` 字段，这是一个可选的位置依赖效果列表
  - 每个条目的格式与位置依赖魔咒效果完全相同
  - 此定义中基于等级的值始终按等级 `1` 求值

### 世界生成

#### 密度函数

##### 更改了 `gradient`

- 当 `axis` 为 `y` 时，`from_coordinate` 和 `to_coordinate` 字段现在还接受垂直锚点

##### 加入了 `domain_warp`

通过为每个采样坐标应用偏移，来采样输入函数。

注意：如果偏移快速、大幅变化，性能可能显著下降。应当谨慎、少量使用此函数。

格式：包含下列字段的对象：

- `input`：密度函数，要采样的输入函数
- `offset_x`：密度函数，应用于采样 X 坐标的偏移
  - 结果会被隐式截断为整数
  - 未指定时默认为 `0.0`
- `offset_y`：密度函数，应用于采样 Y 坐标的偏移
  - 结果会被隐式截断为整数
  - 未指定时默认为 `0.0`
- `offset_z`：密度函数，应用于采样 Z 坐标的偏移
  - 结果会被隐式截断为整数
  - 未指定时默认为 `0.0`

必须至少指定 `offset_x`、`offset_y` 或 `offset_z` 中的一项。

#### 结构模板池元素

##### 加入了可选的 `corner_constraint` 字段

通过在结构模板池元素的边界箱角落采样密度函数，限制该元素的放置。

格式：包含下列字段的对象列表：

- `density_function`：要在边界箱角落采样的密度函数
- `acceptable_density`：双精度浮点数闭区间；某个角落的采样密度落在此范围内时，该角落计为“内部”
- `padding`：`0` 到 `8` 之间的整数，在采样角落前应用于边界箱的内边距
  - 未提供时默认为 `0`
- `corners`：`all`、`top` 或 `bottom` 之一，指定要检查哪些角落
  - 未提供时默认为 `all`
- `required_corners`：`1` 到 `8` 之间的范围，指定要通过检查，必须有多少个角落位于 `acceptable_density` 内

### 标签

#### 流体标签

- 加入了 `#swimmable`，用于玩家能够在其中游泳的流体

#### 物品标签

- 加入了 `#sulfur_cube_archetype/cold`，用于能够放入硫方怪体内、使其变为低温原型的物品

#### 实体类型标签

- 加入了 `#swimming`，用于被视为能够在水中游泳的实体类型
- 加入了 `#flying`，用于被视为能够飞行的实体类型

## 资源包版本 101.0

### 方块精灵图

- 加入了新的方块纹理：
  - `block/snow_bricks.png`

### 音效

- 加入了新的声音事件：
  - `block.ice_crystal.ambient`

### 方块模型

- 移除了方块模型：
  - `block/cube_top`
