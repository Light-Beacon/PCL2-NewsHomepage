## 更改
### 世界生成

- 从洞穴与山崖更新之前的版本升级世界时，现在也会在旧区块下方生成硫磺洞穴。

### 方块、物品与实体的小幅调整

- 红色蘑菇和棕色蘑菇现在可以放置在任何具有完整顶部表面的方块上，不再受光照条件限制。
  - 它们仍然只有在亮度低于 13，或其支撑方块覆盖了光照要求时才能蔓延。

### “图形 API”视频设置

- “默认”现在与“Vulkan 优先”的行为相同。
- 如果检测到启动崩溃，游戏将不再自动更改图形 API 设置。

## 技术更改

- 数据包版本现在为 122.0。
- 资源包版本现在为 98.0。

### 网络协议

#### 新增 `minecraft:mod_list` 自定义数据包负载

- 此数据包用于向服务器告知客户端所安装的模组，以简化调试过程。
- 原版客户端会在配置阶段开始时发送一个空数据包，因为原版客户端并不知道自己安装了哪些模组——这仍然由第三方模组平台负责。

#### 修改 `minecraft:intention` 数据包

- 服务器接收的 intention 数据包中的 `host` 字段现在可以携带额外参数（此前该字段仅保存用于连接服务器的域名）。
  - 新格式类似于 URI 查询字符串：域名后可以选择性地添加 `?`，然后使用 `&` 分隔的 `key=value` 键值对。
  - 空值可以省略（包括 `=` 符号）。
  - 键和值按照标准 URI 规则进行转义（“百分号编码组件”）。
  - 以 `_` 开头的键保留给原版使用。
  - 示例：`example.com?key1=value2&key2`
  - 现在用户可以在服务器列表中的任何“服务器地址”字段中输入属性。
    - 此外，任何形如 `<id>@<host>` 的地址都会被解析为 `<host>?_id=<id>`。
  - 如果服务器使用 SRV DNS 记录，`host` 字段将同时包含原始域名和解析后的域名。
    - 如果解析后的域名与原始域名不同，则解析后的域名会作为“主要”域名，而原始域名会作为 `_o`（“origin”，来源）属性添加。
    - 示例 `host` 字符串：`<redirected domain>?_o=<original domain>:<original port>`；与此同时，intention 数据包中的 `port` 字段将设置为解析后的端口值。
  - 该字段的长度上限已扩展至1024 个字符。
  - 注意：由于 `minecraft:intent` 数据包未加密，因此不应将其中的属性用于任何涉及安全性的用途。

#### 修改 `minecraft:transfer` 数据包

- 新增 `properties` 字段——一个字符串到字符串的属性映射，这些属性将被添加到发送给目标服务器的 `minecraft:intent` 数据包的 `host` 字段中。

### 专用服务器属性

- 新增 `allowed-connection-ids`
  - 一个以逗号分隔的 ID 列表。
  - 如果该列表不为空，服务器将把这些值与 `minecraft:intent` 数据包中的 `_id` 属性进行匹配。
    - 如果没有匹配项，服务器将拒绝连接。
  - 此功能同时适用于状态查询和登录连接，因此任何未在服务器地址中提供正确 `_id` 的用户都无法查看服务器状态，也无法加入服务器。

- 新增 `status-contact-details` 字段
  - 如果该字段不为空，其值将被发送到 `minecraft:status_response` 数据包的 JSON 负载中，并作为 `contact` 属性存在。
  - 此字段用于提供一种联系服务器所有者的方式，即使服务器没有网站或其他相关信息。
  - 此字段面向人类阅读，但对字段格式没有其他限制。

- 新增 `enable-legacy-status` 字段
  - 此选项允许禁用现有的旧版（1.7 之前）服务器状态与 Ping 协议处理。
  - 为保持现有功能，该值默认为 `true`。
  - 注意：必须设置 `enable-status`，服务器才会提供任何状态信息（现代协议或旧版协议均如此）。

## 数据包版本 122.0

- 多噪声生物群系源中的不同生物群系条目，在具有相同偏移量的情况下，不再允许在所有噪声参数上发生重叠。

### 命令

- `fillbiome` 命令现在会以方块精度填充生物群系。
- 将 NBT 从浮点类型转换为整数类型时，现在在向下取整后，总是转换为最接近的有效数值。

### 世界生成

#### 地物

##### 对 `straight_trunk_placer` 的更改

- 新增 `trunk_width` 字段。
  - 可选的整数提供器，用于指定以原点为中心的树干宽度。
  - 默认为 `1.0`。

#### 已放置的地物

- 现在会验证生物群系中所包含的已放置地物在 XZ 平面上的可能范围。
  - 地物放置只能发生在一个 3×3 区块区域内，因此已放置地物不能选择该范围之外的位置。
  - 注意：目前不会考虑地物自身的大小，因此地物本身仍可能溢出区块范围。

#### 放置修饰器

##### 对 `cuboid` 的更改

- `xz_size` 和 `y_size` 现在表示长方体的实际尺寸，而不再隐式地比指定值大 1 个方块。
  - 因此，`xz_size` 为 `2` 时，现在实际生成的是 **2×2** 长方体，而不是 **3×3**。

##### 对 `cuboid` 的更改

- `positions` 现在至少需要包含一个元素。

#### 噪声设置

- 移除了 `default_block` 字段。
  - 现在该字段始终为 `air`，任何其他方块都应通过材质规则（Material Rule）进行定义。

#### 材质条件

##### 更新 `minecraft:steep`

- 不再以依赖处理顺序的方式考虑风蚀恶地的表面扩展所产生的高度修改。

### 标签

#### 生物群系标签

- 新增 `#generated_in_below_zero_retrogen` —— 用于在早于洞穴与悬崖更新的世界下方生成生物群系。
- 新增 `#is_cave` 集合标签。

## 资源包版本 98.0

### 着色器与后处理效果

#### 与顺序无关的透明度着色器

- OIT 算法进行了简化：使用基于深度分桶的累积方式替代基于小波的数学计算。
  - 至少在部分设备上略微提升了性能。
  - 平均而言减少了浮点精度问题。
  - 移除了 `OIT_WAVELET_RANK` 着色器定义。
  - `OIT_COEFF_COUNT` 着色器定义被替换为 `OIT_NUMBER_OF_DEPTH_BINS`。
  - `OIT_COEFF_ATTACHMENT_COUNT` 着色器定义更名为 `OIT_TRANSMITTANCE_TARGET_COUNT`。
