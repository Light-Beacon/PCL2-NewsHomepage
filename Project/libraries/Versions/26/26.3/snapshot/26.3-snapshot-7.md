### 新特性

- 为所有颜色的混凝土块加入了混凝土楼梯和混凝土台阶
- 在废弃营地中加入了新的探险家地图

#### 废弃营地探险家地图

- 加入了显示以下生物群系中其他废弃营地位置的地图：
    - 竹林
    - 樱花树林
    - 桦木森林
    - 斑驳森林
    - 繁花森林
    - 苍白之园
    - 沼泽
    - 风袭森林
- 加入了以下结构的探险家地图：
    - 远古城市
    - 试炼密室
    - 废弃矿井
    - 沙漠神殿
    - 丛林神庙
    - 暖水海底废墟
    - 林地府邸

### 更改

- 坐垫在放置、破坏或交互时不再阻止振动传播
- 更新了废弃营地宝箱的战利品表
- 废弃营地箱子的战利品表中，烟花火箭被替换为火药
- 地图上的玩家图标现在始终显示玩家面朝的方向
- 为 Realms 增加了对加拿大、墨西哥、南非和美国亚利桑那州等更多服务器区域的支持（未来可用时）

#### 探险家地图

- 探险家地图现在作为独立物品，不再是重命名的填充地图，并且每个都有自己的图标：
    - 海洋探险家地图
    - 林地探险家地图
    - 试炼探险家地图
    - 丛林探险家地图
    - 沼泽探险家地图
    - 沙漠村庄地图
    - 平原村庄地图
    - 热带草原村庄地图
    - 雪原村庄地图
    - 针叶林村庄地图
    - 藏宝图
    - 远古城市地图
    - 废弃矿井地图
    - 沙漠神殿地图
    - 废弃营地地图
    - 暖水海底废墟地图
- 地图和空地图也有了新图标
- 这些物品无法从创造模式物品栏中获取
- 旧世界中的现有探险家地图在加载时会自动转换为对应的新物品
- 探险家地图仍然可以在工作台复制，复制品保留其物品类型
- 探险家地图和藏宝图不再能缩小，无论是在工作台还是制图台上都不行
    - 藏宝图之前可以在工作台和制图台缩小
    - 探险家地图之前可以在制图台缩小
- 只有 `#minecraft:extendable_maps` 标签中的地图才能被缩小


### 技术性更改

- 数据包版本现为 `115.0`
- 资源包版本现为 `95.0`
- `level.dat` 现在包含一个 `version_history` 列表，记录文件之前的数据版本

#### 数据包版本 115.0

- 以下方块状态字段已重命名：
    - `Name` → `id`
    - `Properties` → `properties`
- 方块的默认方块状态现在可以通过方块 ID 以紧凑形式直接引用
- `minecraft:exploration_map` 不再改变其应用物品的类型

#### 命令

##### `swing` 的更改

- 对玩家使用时，不再重置玩家的攻击强度
- 添加了一个新的可选参数来设置要播放的挥动动画
    - 可选值：`whack`（重击）、`stab`（戳刺）
    - 如果省略，默认为 `whack`
- 添加了一个新参数来设置挥动动画的持续时间（如果提供）
    - 格式：正时间值（默认为 tick）
    - 如果省略，默认为 `6t`

#### 数据组件

##### 增加了 `minecraft:attack_animation`

- 物品攻击时播放的动画
- 格式：包含以下字段的对象：
    - `type` - 挥动类型
    - `swing` - 动画持续时间
